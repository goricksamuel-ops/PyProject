Project Requirements:
Analysis of Scottish Census data
- Check For Errors/Inconsistencies in provided csv file
- Prune Dataset for analysis
- Perform Descriptive Analysis of the Dataset
- Build Bar plots of Age Group & Occupation
- Build Pie Charts of Ethnic Groups & Health Descriptors

Installation Requirements:
- Python
- pandas
- matplotlib
- jupyter
- ipykernel

To install the above open a Powershell terminal and run:
    python -m pip install pandas matplotlib jupyter ipykernel
